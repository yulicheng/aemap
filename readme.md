# 项目目标

考虑一种动态地址映射，支持将48位虚地址动态映射到52位新的地址，应用代码中的指针低32位为offset，32到51位为映射索引，52位及以上忽略。应用代码每次ld或st时使用的地址叫VVA，需要将VVA高51到32位转换成真实的VA的高48到32位，VA低32位直接使用VVA低32位。

一种实现方式是每次ld和st前进行一次内联查表，实现上述映射，并合并低32位，将指针VVA转为VA，再使用VA执行ld或st指令。

本项目需要用最优的指令实现以上操作，并且设计一个测试框架，测试这种软件转换带来的overhead。测试用例需要覆盖重复访问相近VVA从而使得映射表在L1命中，以及随机访问VVA使得映射表cache miss等等场景，请进一步补充测试用例，覆盖常见的软件访存pattern。

以上操作的实现方式在design.md中具体描述。测试框架以及对应的测试用例在test.md中详细描述。
